← Websites
1Add the widget

Put this snippet before </body> and keep the site key public.

2Listen for verification
When the visitor completes the challenge, the widget emits a verification event.
const captcha = document.querySelector('vin-captcha');

captcha.addEventListener('vin-captcha-verified', (event) => {
  const { token } = event.detail;
  // Send token to your backend.
});
3Verify on your backend
Your server sends the site key, secret key and token to BeeCaptcha. Never send the secret from browser code.
⚠ Secret keys are server-only. Tokens are short-lived and single-use.
