Protect a website in three steps.

Use a public site key in the browser and keep the secret key on your server.

1Load the widget
<script src="https://zjghuovefnbuliovttqa.supabase.co/functions/v1/widget?site_key=YOUR_SITE_KEY"></script>
<vin-captcha data-vin-captcha="YOUR_SITE_KEY"></vin-captcha>

The site key is designed to be public. Never put the secret key into frontend JavaScript.

2Read the verification event
document.addEventListener("vin-captcha-verified", (event) => {
  const token = event.detail.token;
  // Send token to your backend.
});

The event contains a short-lived verification token for your server to verify.

3Verify on your backend
POST /functions/v1/captcha-verify
Content-Type: application/json

{
  "site_key": "YOUR_SITE_KEY",
  "secret_key": "YOUR_SECRET_KEY",
  "verification_token": "TOKEN_FROM_WIDGET"
}

Only your backend should send the secret key. A successful response returns success: true.

Supported CAPTCHA types

The dashboard currently supports Visual Select, Image Select and Math Challenge. Additional types can be registered through the CAPTCHA type catalog without changing the verification contract.
